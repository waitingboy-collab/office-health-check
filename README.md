# Office Health Check

Проверява офис компютър с един клик и прави отчет в PDF, който можеш да пратиш на човека, който поддържа компютрите. Програмата само чете и не променя нищо по компютъра.

**Свали:** [последната версия](https://github.com/waitingboy-collab/office-health-check/releases/latest/download/OfficeHealthCheck-Setup.exe) · Windows 10/11, 64-bit, не изисква .NET и админ права.

## Какво проверява

| Група | Проверка | Кога е „Внимание“ / „Проблем“ |
|---|---|---|
| Windows | Поддръжка на версията | до 90 дни до края / вече без обновления |
| | Последно обновление | над 35 дни / над 60 дни |
| | Чака рестарт | има инсталирани обновления, които чакат |
| | Време без рестарт | над 14 дни |
| | Активация | не е активиран |
| Защита | Антивирусна | остарели дефиниции / изключена или липсва |
| | Защитна стена | изключена за частна мрежа / за обществена мрежа |
| Дискове | Свободно място (всеки диск) | под 20% или 15 GB / под 10% или 5 GB |
| | Състояние на диска | дискът съобщава предупреждение / повреда |
| Ресурси | Оперативна памет | над 90% заета |
| | Временни файлове | над 3 GB |
| | Програми при стартиране | над 15 |
| Принтери | Spooler, принтери, опашка | принтер с грешка или 5+ документа / спрян spooler или повреден принтер по подразбиране |
| Архив | Последен файл в папката за архив | над 7 дни / над 30 дни, липсваща или празна папка |
| Мрежа | Интернет и DNS | няма DNS / няма връзка |

Датите за поддръжка на Windows са в `src/OfficeHealthCheck.Core/WindowsLifecycle.cs`. Обнови ги, когато Microsoft пусне нова версия.

## Отчет

„Запази отчет (PDF)“ прави A4 отчет чрез Microsoft Edge, който има всеки Windows 10/11. Ако Edge липсва, отчетът се записва като HTML.

## Без прозорец (Планировчик на задачи)

```
OfficeHealthCheck.exe --report "\\server\IT\Отчети\%COMPUTERNAME%.pdf"
```

Кодът на изход показва резултата: `0` наред, `1` внимание, `2` проблем, `3` грешка. Така може да се пуска всяка седмица на всички компютри в офиса.

## Структура

```
src/OfficeHealthCheck.Core     правилата и HTML отчетът (без Windows зависимости)
src/OfficeHealthCheck          прозорецът и четенето от Windows (WMI, регистър)
tests/OfficeHealthCheck.Tests  xUnit тестове за всеки праг и за отчета
installer/                     Inno Setup
```
